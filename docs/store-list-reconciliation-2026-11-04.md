## 화면 수치와 표시 로직

- 가맹점 현황·점포 수는 동일 CSV를 사용한다. 실제 목록·수량 API를 호출하는 오프라인 검증에서 모두 201곳을 반환했고, 목록의 전체 필드가 원본에 대응된 CSV 201개와 같았다. 외부 좌표 조회는 이 검증에서 모의 응답으로 대체했다.
- 화성봉담점처럼 월만 있는 날짜도 5월 오픈 라벨과 월별 정렬에 반영하도록 수정했다.
- 가맹 홍보 문구에서 API 응답 전/실패 시 임의의 157명을 표시하던 고정값을 제거했다.
- 기존 NEW 규칙은 전월 오픈 기준을 유지했다. 월 경계는 현재 브라우저의 현지 시각을 사용한다.

별도 성과 차트(`AchievementRankSection`)는 CSV와 연결되지 않은 고정 홍보 수치다. 아래 차이를 발견했으나, 과거 실적과 현재 운영 지점수의 집계 범위가 다를 수 있어 차트의 수치·100호점·150호점 달성 문구는 변경하지 않았다. 제공된 원본만으로 당시 달성 실적을 확정할 수 없다.
